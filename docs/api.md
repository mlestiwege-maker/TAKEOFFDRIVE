# API Reference

Base URL: `http://localhost:8000`. Interactive docs (Swagger UI) are
auto-generated by FastAPI at `/docs`, and the raw OpenAPI schema at
`/openapi.json` — this file is a human-readable summary of the same
surface.

All endpoints except `/api/health`, `/api/auth/*` and admin login require
`Authorization: Bearer <jwt>`.

## Auth (`/api/auth`)

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/register` | none | Create a driver account (phone, optional email, password) |
| POST | `/send-otp` | none | Generate and "send" (log/echo) an OTP for a phone number |
| POST | `/verify-otp` | none | Verify the code; returns a JWT on success |
| POST | `/login` | none | Password login (phone or email as identifier); returns a JWT |
| POST | `/logout` | driver/admin | Revokes the calling token (by `jti`) so it's rejected on any further use, even before it would have naturally expired |
| GET | `/me` | driver/admin | Current user's identity |

## Drivers (`/api/drivers`)

| Method | Path | Description |
|---|---|---|
| GET | `/me` | Get (or lazily create) the caller's driver profile |
| POST` / PUT `/profile` | Upsert personal/contact/identity fields |

## Vehicles (`/api/vehicles`)

Standard CRUD, scoped to the authenticated driver: `GET /`, `POST /`,
`PUT /{id}`, `DELETE /{id}`.

## Documents (`/api/documents`)

| Method | Path | Description |
|---|---|---|
| GET | `/` | List the caller's uploaded documents |
| POST | `/upload` | Multipart upload: `document_type` + `file` |
| GET | `/{id}/file` | Download/view a document (owner only) |
| DELETE | `/{id}` | Remove a document |

## Applications (`/api/applications`)

| Method | Path | Description |
|---|---|---|
| GET | `/me` | Get (or lazily create) the caller's draft/current application, with full nested detail |
| POST | `/` | Submit the application (validates completeness; enforces the state machine) |
| GET | `/{id}` | Fetch the caller's own application by id |

## Admin (`/api/admin`) — requires `role: ADMIN`

| Method | Path | Description |
|---|---|---|
| GET | `/applications?status=&search=` | List non-draft applications, optionally filtered/searched |
| GET | `/applications/{id}` | Full application detail (profile, vehicle, documents, review history) |
| POST | `/applications/{id}/approve` | Decision: APPROVED |
| POST | `/applications/{id}/reject` | Decision: REJECTED (notes required) |
| POST | `/applications/{id}/request-correction` | Decision: CORRECTION_REQUIRED (notes required) |
| GET | `/documents/{id}/file` | View any driver's document |
| GET | `/drivers` | List all drivers |
| GET | `/drivers/{id}` | Single driver detail + their latest application summary |
| GET | `/analytics/summary` | Status counts, approval rate, avg. review turnaround, submissions/day (last 30 days) — powers the admin dashboard charts |

## Rate limiting

`/api/auth/register`, `/send-otp`, `/verify-otp` and `/login` are rate
limited per client IP (via `slowapi`): 10/min, 5/15min, 10/15min and
10/15min respectively. Exceeding the limit returns `429 Too Many Requests`.
Disable with `RATE_LIMIT_ENABLED=false` (tests do this).

## Error format

FastAPI's default shape: `{"detail": "<message>"}` for single errors, or
Pydantic's validation error list for 422s. The frontend's
`extractErrorMessage` helper (`frontend/src/services/api.ts`) normalizes
both into a single string for display.
